# G-Tune Pro

Professional-grade chromatic guitar tuner with real-time feedback. Built with React and Vite.

## Features

- **Real-time Chromatic Tuning**: High-precision pitch detection.
- **Visual Feedback**: Sleek gauge interface for accurate tuning.
- **String Selector**: Quickly switch between standard guitar strings (EADGBE).
- **Responsive Design**: Works on mobile and desktop browsers.

## Deployment (Recommended)

The easiest way to deploy this project is via **Vercel** or **Netlify** using GitHub integration.

1. Connect your GitHub repository to [Vercel](https://vercel.com).
2. Vercel will automatically detect the Vite configuration and deploy the app.

## Run Locally

**Prerequisites:** Node.js (LTS)

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the app:**
   ```bash
   npm run dev
   ```
